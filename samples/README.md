# Sample jobs

Every file here runs through the engine in `backend/tests/test_samples.py`, and
the result is compared with `expected/<file name>.json`. Add a file, run the
tests once to create its expected result, check that result by hand, and
commit both.

## synthetic/

Generated by `backend/scripts/make_samples.py`. They imitate real exports
without copying anyone's files.

| File | Imitates | What it exercises |
|---|---|---|
| `laser_S235_3mm_3000x1500.dxf` | Fibre-laser nest from CAM software | Parts placed as blocks, sheet on its own layer, washers nested inside flange holes, marking and text layers to ignore |
| `inox_304_1.5mm_2500x1250.dxf` | Nest exported as loose geometry | Lines and arcs with tiny gaps, sheet outline on layer 0, no layer names |
| `plasma_S355_10mm_2000x1000.nc` | Plasma table program | M07/M08 torch switching, lead-ins, holes cut before outlines, no sheet in file |
| `router_MDF_18mm_2440x1220.nc` | CNC router program | Tool-centre paths, two depth passes, shallow hinge bores that are not through-cuts |
| `cuisine_MDF_18mm.csv` | Panel-saw cut list from a spreadsheet | French headers, semicolons, decimal commas, grain direction, panel size row |
